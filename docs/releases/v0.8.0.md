# PowerMap v0.8.0

Release date: 2026-07-31

## Highlights

- Ship `powermap-relay`, a separately delivered upstream-compatible iroh relay. Each release
  includes verified Linux AMD64 and ARM64 archives, plus a multi-architecture Docker image.
- Configure up to eight private HTTPS relay URLs and an optional relay bearer token from the
  Nodes page or the root `[relay]` configuration section. Empty URLs retain iroh's default
  relay selection.
- Share a node credential with relay settings only when explicitly selected. This makes paired
  deployments portable without exposing the relay token in the default shared JSON.

## Deployment

Run the relay on an address with a DNS name and a valid TLS certificate. It must own TCP `80`,
TCP `443`, and UDP `7842`; do not place an ordinary HTTP reverse proxy in front of the relay
HTTPS port. See [relay deployment](../../relay/README.md) for the Compose template, metrics,
access-token configuration, and operational constraints.

## Compatibility

Existing configurations and shared credentials remain compatible. A missing `[relay]` section
or a credential without a `relay` object continues to use the receiver's existing relay setting,
which defaults to iroh's relay map.
