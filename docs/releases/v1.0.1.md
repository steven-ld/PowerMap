# PowerMap v1.0.1

Release date: 2026-11-18

## Highlights

- The admin console now rejects requests whose `Host` is not an accepted name, and verifies
  `Origin` / `Sec-Fetch-Site` on writes. This closes DNS rebinding and CSRF against the local
  management API; every response carries security headers and `/api/*` is `no-store`.
- All tunnel handshakes are bounded. A peer that opens a stream and never sends a header can no
  longer hold a connection and its concurrency slot indefinitely.
- Reverse registration binds every intranet listener before answering OK. A partial bind is
  reported to the caller and can be retried instead of silently appearing successful.
- `powermap.key` and exported `powermap.credential.json` are written and repaired to owner-only
  permissions, so a peer token is no longer readable by other local users.
- The console is usable on phones: the tab bar becomes a single scrolling row that reveals the
  active tab, mapping and domain lists render as labelled cards, and forms fit a 390 px viewport.

## Compatibility

`web_allowed_hosts` is a new optional list under `[access]`. When the console is reached through
a reverse proxy that forwards `Host: <proxy domain>`, add that domain to the list or the
management API answers `403`. Direct loopback access, `web_bind`'s own host, and TLS terminated
by PowerMap itself (`web_tls_cert` / `web_tls_key`) need no entry.

Configurations are unchanged for normal use. Existing identity and credential files are
re-permissioned on read; no migration step is required.

## Fixed

- Legacy config migration runs only when the file actually parses as the old schema, so a
  malformed unified config is reported instead of being migrated and deleted.
- Self-update replaces the binary with a single atomic rename over a hard-link backup, removing
  the window in which no executable existed in the directory.
- Update downloads and release lookups have connect and total timeouts.
- `from_hex` no longer panics on non-ASCII input.
- Mapping listeners back off and retry on transient `accept()` errors instead of going offline
  permanently.
- Changing a mapping between TCP and UDP rebinds the socket, and the local HTTP header read has
  a 10 s timeout.

## Upgrade

Use the in-console updater or install the matching release archive for your platform. If you
downgrade to v1.0.0, review `web_allowed_hosts` in `powermap.toml` first — v1.0.0 ignores the
key but v1.0.1 will reject proxied requests without it.
